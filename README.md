# Web Technology Lab (WTL) - Assignments Repository

Comprehensive practical lab work and project submissions for **Web Technology Laboratory (WTL)**, Third Year (TY) Engineering.

---

## 📁 Repository Structure (`WTL-Assignments`)

All practical assignments are organized cleanly inside the [`WTL-Assignments/`](./WTL-Assignments) folder:

```text
WTL-Assignments/
├── assignment_1/       # Responsive Hospital & Ordering Portal (HTML, CSS, Bootstrap)
├── assignment_2/       # Dynamic To-Do List Application (HTML, CSS, JavaScript DOM)
├── assignment_3/       # Fetch Public API with Async/Await (JavaScript, REST API)
├── assignment_4/       # TypeScript Web App - Student Grade Portal (TypeScript)
├── assignment_5/       # React JSX Functional Components, Props & useState
├── assignment_6/       # React App with Axios API Fetching & Loading/Error States
├── assignment_7/       # Controlled User Registration Form with Validation (React)
├── assignment_8/       # PHP MySQL CRUD Student Record System (Apache, MySQL)
├── assignment_9/       # RESTful API with Node.js & Express (CRUD + Postman Collection)
├── assignment_10/      # Node.js + Express + MongoDB Mongoose CRUD & Serverless API
├── assignment_11/      # User Auth with JWT, bcrypt & Protected Routes (Express, JWT)
└── practice_files/     # Practice scripts (PHP forms, HTML demos)
```

## 🚀 Quick Start Guide

### Prerequisites
- Modern Web Browser (Chrome / Edge / Firefox)
- [Node.js](https://nodejs.org/) (v16 or higher)
- [XAMPP](https://www.apachefriends.org/) (for Assignment 8 PHP & MySQL)
- [MongoDB Community Server](https://www.mongodb.com/try/download/community) or MongoDB Atlas (for Assignment 10)

### Running Backend Projects
For assignments 9, 10, and 11, install dependencies and start the server:

```bash
# Assignment 9 (Express API)
cd WTL-Assignments/assignment_9
npm install
node server.js

# Assignment 10 (MongoDB Mongoose CRUD)
cd WTL-Assignments/assignment_10
npm install
node server.js

# Assignment 11 (JWT Authentication)
cd WTL-Assignments/assignment_11
npm install
node server.js
```
